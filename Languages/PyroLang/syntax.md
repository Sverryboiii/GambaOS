# Syntax
PyroLang has a very weird syntax.
You could associate it with an esoteric language, but it is used for real programming throughout GambaOS.

GET: Puts a builtin function in the global functions.
[GET {builtin function name}]
GETF: Get and run an external file.
[GETF {path/to/external/file.pr}] (modules/ gets a builtin module)
SET: Set a variable.
[SET {variable name} {value}]

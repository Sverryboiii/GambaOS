# PyroLang
PyroLang is a very widely used programming language across GambaOS.<br>
PyroLang is also a notoriously slow language, but that will only affect starting up apps.

### Use cases:
PyroLang is used in a lot of parts of GambaOS, 
but mostly it's used for the interactive part of websites on GambaOS.<br>
However, you can also use it to create apps and simple scripts.<br>

### Basics:
PyroLang isn't a very big language yet, but it covers the essentials.<br>
To work with PyroLang you need to get used to a whole new syntax.<br>
The syntax of PyroLang is unpredictable, but still possible to learn.<br>

### Make a website:
To make a website you first need to learn GML which is an easy to learn Markup-Language.<br>
After that you can make the sites interactive using PyroLang.<br>
With PyroLang you can easily change sites or give different inputs.<br>

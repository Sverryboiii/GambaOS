# Builtins:
To get a builtin in PyroLang you have to import it.<br>
You do this by typing `GET` following with the builtin name.

### All builtins list:
 - `eq`: Test is something equals something else.
 - `avg`: Get the average of all inputs.
 - `max`: Get the highest of all inputs.
 - `min`: Get the lowest of all inputs.
 - `add`: Add 2 or more values.
 - `sub`: Subtract 1 or more values from the first value.
 - `mult`: Multiply 2 or more values.
 - `div`: Divide 1 or more values from the first value.
 - `out`: Print something to the console.
 - `in`: Ask the user for an input (Waits until input is given).
 - `exit`: Exit the script.
 - `up_g`: Update a global variable (used in imported files).
 - `time`: Get the time in a specified format.
 - `gml`: Open an url.
 - `read`: Read a file.
 - `write`: Write a file.
 - `json_pack`: Set a value in a JSON dict.
 - `json_upack`: Get a value from a JSON dict.
 - `to_s`: Convert any data-type to String.
 - `type`: Get the type of value.
 - `split`: Split a string on every chosen sub-string (Receive the chosen index).
